title: image-generation
description: "The image-generation skill creates and edits images through the configured LiteLLM endpoint. Set image_model to an image model id on that endpoint."
---

Creates and edits images by calling the configured LiteLLM endpoint. The model id is `image_model`. It is sent unchanged. An empty `image_model` turns the skill off.

## Setup

Set both of these in `config.json` or on the model page in the [web console](/channels/web):

| Field | Meaning |
| --- | --- |
| `litellm_api_base` | http(s) URL ending in `/v1` |
| `image_model` | Image model id the proxy lists |

The same pair drives the built-in image tool. No separate vendor key is used.

To pin a different id for one call, pass `model` to the skill script. That id must also exist on the same endpoint.

## Enabling and disabling

- **`image_model` set**: the agent can call the skill for a drawing request
- **`image_model` empty**: the skill stays unavailable until an image model id is set

```text
/skill disable image-generation
/skill enable image-generation
```

Terminal equivalents: `maia skill disable image-generation` and `maia skill enable image-generation`.

## Parameters

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `prompt` | string | Yes | — | Image description |
| `image_url` | string / list | No | null | Local path or URL of an image to edit. A list fuses several images |
| `quality` | string | No | auto | `low` / `medium` / `high` when the model accepts it |
| `size` | string | No | auto | `512` / `1K` / `2K` / `3K` / `4K`, or pixels such as `1024x1024` |
| `aspect_ratio` | string | No | null | `1:1` / `3:2` / `2:3` / `16:9` / `9:16` / `21:9` |

## Common uses

- **Text-to-image**: illustrations, posters, icons, avatars
- **Image-to-image**: restyle or edit an existing file
- **Multi-image fusion**: combine several reference images

<Note>
- Allow at least 300 seconds for the script. The HTTP timeout is 300 seconds.
- Input images are compressed to at most 4 MB, longest edge at most 4096 px.
- `quality` and `size` are omitted when you leave them at `auto`, so the model can choose.
</Note>

**Maia** is a local agent forked from [CowAgent](https://github.com/zhayujie/CowAgent) (MIT, Copyright (c) 2022 zhayujie, Copyright (c) 2026 dubhagen (github.com/dubhagen)). Chat runs in the web console. The local terminal is also available. Every model call goes to one LiteLLM endpoint. The current version is 0.99.0.

## Core Capabilities

  <Card title="Autonomous Task Planning" icon="brain" href="/intro/architecture">

## Quick Start

Run one of the commands below to install, configure, and start Maia in a single step:

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    git clone https://github.com/dubhagen/Maia.git
    cd Maia
    bash run.sh
    ```
  </Tab>
  <Tab title="Windows (PowerShell)">
    ```powershell
    git clone https://github.com/dubhagen/Maia.git
    cd Maia
    .\scripts\run.ps1
    ```
  </Tab>
  <Tab title="Docker">
    ```bash
    git clone https://github.com/dubhagen/Maia.git
    cd Maia
    docker compose -f docker/docker-compose.yml up -d --build
    ```
  </Tab>
</Tabs>

Once started, open `http://localhost:9899` to access the **Web console** — chat, set the LiteLLM base URL, and install skills from a git URL.

---
title: web_search
description: "Web search uses a SearXNG instance you configure. It is off until that URL is set."
---

`web_search` queries a SearXNG instance. It does nothing until you set the URL. There is no default public instance and no hosted search API.

```json
{
  "tools": {
    "web_search": {
      "searxng_url": "http://127.0.0.1:8080"
    }
  }
}
```

You can set the same value with the `SEARXNG_URL` environment variable. The models screen saves this URL from the search card.
